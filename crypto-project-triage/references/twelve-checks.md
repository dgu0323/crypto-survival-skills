# 十二条常识清单

逐条：是 / 否 / 未知。未知按「不付款」处理。

1. 没有代币奖励以后仍然有人使用，需求才更接近真实。
2. 项目收入增长，不代表代币持有人自动分享收入。
3. 代币有功能，不代表它能够形成持续净需求。
4. 单价低不代表便宜，流通量小也不代表上涨空间大。
5. 未来释放的筹码，最终需要未来真实需求承接。
6. 团队、机构、顾问、平台、KOL 和社区成员的利润来源不同。
7. 融资能力可以延长项目寿命，不能替代真实商业模式。
8. 国库里大量自己的代币，不等于拥有同等金额的可用现金。
9. 回购、销毁、质押都要追溯资金来源和新增供应。
10. 社区不允许质疑时，信息质量通常正在恶化。
11. 一个项目值得使用、值得工作和值得购买代币，是三种不同结论。
12. 回答不清楚的项目未必是坏项目，但一定超出了当前能够承担的认知范围。

补充（写进定性句，不另占一行）：先分清 meme、功能代币、NAV/收益凭证。看错类别时，1–4 条的「是」没有意义。
